# EXAMPLE: HOW TO BUILD A NEW "SOURCE" MODULE

In Nightwatcher, a "Module" is usually a piece of code that does one specific job. Let's imagine we want to add a new module that reads "Twitter" for stock tips.

Here is how you would build it (Simplified):

### 1. The "Gatherer" (The Scout)
This part of the module goes out and finds information.
```javascript
async function scoutTwitter() {
  // 1. Go to Twitter
  // 2. Look for $TSLA or $AAPL
  // 3. Bring back the tweets

}
```

### 2. The "Filter" (The Bouncer)
The robot shouldn't believe everything it hears. The Filter decides if a tip is "Noise" or a "Signal."
```javascript
function bouncer(tweet) {
  if (tweet.followers < 100) return "NOISE"; // Ignore small accounts
  if (tweet.text.includes("MOON")) return "SIGNAL"; // This might be interesting!
  return "NOISE";
}
```

### 3. The "Researcher" (The Brain)
Once we have a good signal, we send it to the LLM (Gemini) to ask, "Is this a smart idea?"
```javascript
async function askGemini(signal) {
  const answer = await gemini.ask("Should I buy this stock based on this tweet?");
  return answer.verdict; // "BUY" or "SKIP"
}
```

### 4. Putting it in the Worker (The Connection)
In your `src/index.ts`, you would tell the main robot to use this new scout:
```typescript
// Inside the main loop
const twitterSignals = await twitterModule.scout();
for (const sig of twitterSignals) {
  const decision = await brain.research(sig);
  if (decision === "BUY") {
    await tradeBot.execute(sig);
  }
}
```
