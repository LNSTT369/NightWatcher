# NIGHTWATCHER Work Summary - April 1, 2026

## 1. Unified Brand Transformation
Today we officially retired "V2" and "v1" identifiers, unifying the system under the single name **NIGHTWATCHER**. 

### Branding Changes:
- **Renamed Agent Script**: `agent-v1.mjs` → `agent.mjs`.
- **Renamed Configuration**: `agent-config.json` → `nightwatcher-config.json`.
- **Renamed Activity Logs**: `agent-logs.json` → `nightwatcher-logs.json`.
- **UI Updates**:
  - Removed "v2" label from the Dashboard header (`App.tsx`).
  - Standardized console startup text to `NIGHTWATCHER - Simple Trading Agent`.
  - Updated all `README.md` and `SetupWizard.tsx` documentation to match the new filenames.

## 2. Trading Strategy Enhancements
Resolved issues where equity (stock) signals were being filtered out incorrectly.

### Key Refinements:
- **Heuristic Signal Scoring**: Replaced the non-existent `llm-prompt` tool gateway with a robust **Quality Score (0-10)** system. This scores signals based on message volume, net sentiment, and bullish ratios.
- **Lowered Sentiment Threshold**: Updated `min_sentiment_score` to `0.2` (from 0.4) to increase responsiveness to trending stock sentiment.
- **Enhanced Diagnostics**: Signals filtered by the "noise" filter now log their specific scores and metrics (Bullish count/Total count) to `nightwatcher-logs.json` for easier troubleshooting.

## 3. Critical bug Fixes
- **Equity Execution Fix**: Resolved Alpaca validation errors (`fractional orders must be DAY orders`) by implementing dynamic `time_in_force` selection. The system now correctly uses `day` for stocks and `gtc` for crypto.
- **Multi-Provider LLM Support**: Fully configured `.dev.vars` for `openai`, `gemini`, and `ollama` providers, currently set to `gemini` for stable remote analysis while local Ollama instances are offline.

## 4. Current Operational State
- **Dashboard**: Running and reachable.
- **Agent**: Successfully gathering and executing signals via `node agent.mjs`.
- **Market Presence**: Active in both Equities (Market Hours) and Crypto (24/7).
